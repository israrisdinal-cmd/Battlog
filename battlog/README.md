# BattLog

BattLog is a single-page EV (electric vehicle) battery and charging log tracker. It runs entirely in the browser, stores your session data locally, and helps you record trips, state of charge, and charging events over time.

**Version:** V1.5 FIX — AVG GoRide, km muter, efisiensi jam, integrasi SiGan/Lapkeu.

## Files

- `index.html` — main app (open this)
- `sw.js` — service worker for offline cache

## How to open

Open `index.html` in a modern web browser (Chrome, Firefox, Safari, or Edge). For offline use, serve the folder over HTTP or open via `file://` and allow the service worker when prompted.
